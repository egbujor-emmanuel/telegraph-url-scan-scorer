# Telegraph URL_SCAN Scoring Module (candidate)

Compiled WASM scoring module for the Telegraph Protocol `URL_SCAN` intent.

- Target: `wasm32-unknown-unknown`
- Exports: `alloc`, `dealloc`, `rank_answer`
- keccak256: `0x8e3c54f1b89a6e2884225f6a40fd01549a8c930d71b6ba30f8ecc3ad855364be`

This repository exists solely to publicly host the exact binary referenced by an on-chain `registerWasm` call. It is independent of the `telegraph-url-scan-miner` repository, which hosts the separate Track 1 miner.
